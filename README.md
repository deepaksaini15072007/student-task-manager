# Student Task Manager

A simple web application that helps students manage assignments, projects, and deadlines in one place.

## Features

- Add new tasks
- Set task deadlines
- Set task priority
- Complete and undo tasks
- Delete tasks
- Search tasks
- Filter tasks by priority and status
- Automatic deadline status
- Overdue task detection
- Due Today and Due Tomorrow status
- Upcoming task status
- Dashboard with task progress
- Data saved using LocalStorage

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Start adding tasks.
